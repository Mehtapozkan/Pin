# Pin

Find the change notice, compare it with the departure board, and open either original from the answer.

[Project website](https://mehtapozkan.github.io/Pin/) · [Download Pin for Xcode](https://mehtapozkan.github.io/Pin/Pin-source.zip)

## Reconstruct an itinerary

Pin reads labelled travel records with Apple Vision. It matches the train booking, applies the saved schedule change and calculates the time between your flight and train.

## See exactly where an answer came from

For train R581, the change notice says platform 3. The board photographed at 23:58 says platform 5. Both remain visible with their own source. Tap either to inspect the original, then tap Done to return.

## Correct or forget a reading

Pin connects saved interpretations to their photos. You can correct a detail or remove its reading from Pin while keeping the original in Apple Photos.

## Run the local preview

Unpack Pin, iBrain and Pin-Qwen-6bit into sibling folders on an Apple silicon Mac. Follow the Pin README to start Nativ and run the SwiftUI demo in Xcode. The sample pack includes eight fictional photos.

## Verification

133 portable Pin tests passed. In the itinerary replay, the integrated app passed 74 of 74 fictional cases. The verified model-backed demo ran Pin in the iPhone Simulator with Nativ 0.4.3 serving Qwen on the Mac. The six-bit checkpoint awaits physical iPhone verification.
